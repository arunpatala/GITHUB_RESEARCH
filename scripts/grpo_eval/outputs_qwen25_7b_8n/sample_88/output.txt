Let's define the number of copies sold by Harald as \( x \).

Since Marilyn's first record sold 10 times as many copies as Harald's, the number of copies sold by Marilyn is \( 10x \).

The total number of copies sold by both is given as 88,000. Therefore, we can set up the following equation:

\[
x + 10x = 88,000
\]

Combining like terms, we get:

\[
11x = 88,000
\]

To solve for \( x \), we divide both sides by 11:

\[
x = \frac{88,000}{11} = 8,000
\]

Thus, Harald sold \( 8,000 \) copies.
