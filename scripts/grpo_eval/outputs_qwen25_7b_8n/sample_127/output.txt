To determine the total number of friends Lily and Amy have together, we start by identifying the number of friends each has.

1. **Determine the number of friends Amy has:**
   According to the problem, Amy made 20 more friends than Lily. Since Lily made 50 friends, we can calculate the number of friends Amy has by adding 20 to Lily's number of friends:
   \[
   \text{Number of friends Amy has} = 50 + 20 = 70
   \]

2. **Calculate the total number of friends:**
   To find the total number of friends Lily and Amy have together, we add the number of friends each has:
   \[
   \text{Total number of friends} = \text{Friends Lily has} + \text{Friends Amy has} = 50 + 70 = 120
   \]

Therefore, the total number of friends Lily and Amy have together is \(\boxed{120}\). #### 120
