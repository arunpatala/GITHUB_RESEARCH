First, let's find the number of boys in Dr. Wertz's school. Since there are twice as many boys as girls, we can calculate the number of boys by multiplying the number of girls by 2.

Number of boys = 2 * Number of girls

Given that there are 60 girls:

Number of boys = 2 * 60 = 120

Next, we'll determine the total number of students by adding the number of boys and girls together:

Total number of students = Number of boys + Number of girls
Total number of students = 120 + 60 = 180

We're given that 5 students correspond to 1 teacher. So, to find out how many teachers are needed, we divide the total number of students by the ratio of students per teacher:

Number of teachers = Total number of students / 5 students per teacher
Number of teachers = 180 / 5 = 36
