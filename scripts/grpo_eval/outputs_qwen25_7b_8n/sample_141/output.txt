- \( b \) as the number of baby bees.
- \( w \) as the number of worker bees.

From the problem statement, we have the following relationships:
1. There are twice as many baby bees as queens: 
   \[
   b = 2q
   \]
2. There are twice as many worker bees as baby bees:
   \[
   w = 2b
   \]

We also know that the total number of bees (i.e., the sum of queen, baby, and worker bees) is 700:
\[
q + b + w = 700
\]

Substituting the expressions for \( b \) and \( w \) in terms of \( q \):
\[
q + 2q + 2(2q) = 700
\]

Simplify and solve for \( q \):
\[
q + 2q + 4q = 700
\]
\[
7q = 700
\]
\[
q = 100
\]

Now, using the value of \( q \), we can find \( b \) and \( w \):
\[
b = 2q = 2 \times 100 = 200
\]
\[

- Let \( Q \) represent the number of queen bees.
- Since there are twice as many baby bees (\( B \)) as queens, then \( B = 2Q \).
- Similarly, since there are twice as many worker bees (\( W \)) as baby bees, then \( W = 2B \).

We are given that the total number of bees in the hive is 700. Therefore, we have:
\[ W + B + Q = 700. \]

Substitute \( B \) with \( 2Q \):
\[ W + 2Q + Q = 700. \]
This simplifies to:
\[ W + 3Q = 700. \]

Now substitute \( W \) with \( 2B \), but since \( B = 2Q \), hence \( W = 2 \cdot 2Q = 4Q \). So, we now substitute \( W \) into the equation:
\[ 4Q + 3Q = 700, \]
which simplifies to:
\[ 7Q = 700. \]

Divide both sides by 7 to find \( Q \):
\[ Q = 100. \]

Now, we use \( Q = 100 \) to find the number of worker bees (\( W \)):
\[ W = 4Q = 4 \times 100 = 400. \]
