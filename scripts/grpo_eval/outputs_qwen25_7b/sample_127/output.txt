To determine the total number of friends Lily and Amy have together, we need to follow these steps:

1. Identify the number of friends Lily has.
2. Calculate the number of friends Amy has based on the information given.
3. Add the number of friends Lily and Amy have to find the total.

First, we know from the problem statement that Lily made 50 friends. We can represent this as:
\[ \text{Number of friends Lily has} = 50 \]

Next, we are told that Amy made 20 more friends than Lily. Therefore, we can calculate the number of friends Amy has by adding 20 to the number of friends Lily has:
\[ \text{Number of friends Amy has} = 50 + 20 = 70 \]

Now, to find the total number of friends Lily and Amy have together, we add the number of friends each has:
\[ \text{Total number of friends} = \text{Number of friends Lily has} + \text{Number of friends Amy has} = 50 + 70 = 120 \]

Thus, the total number of friends Lily and Amy have together is:
\[ \boxed{120} \]
#### 120
