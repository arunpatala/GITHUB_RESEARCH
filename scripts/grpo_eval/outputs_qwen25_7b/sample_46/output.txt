To determine how many Post-it notes were in the package Candice purchased, we need to follow these steps:

1. **Initial Post-it Notes**: Candice started with 80 Post-it notes.
2. **Post-it Notes Purchased**: Let \( x \) be the number of Post-it notes in the package she bought.
3. **Post-it Notes Used at Work**: She used 220 Post-it notes at the coffee shop.
4. **Remaining Post-it Notes**: After all the usage, she had 23 Post-it notes left.

We can set up the equation based on the information given:
\[
80 + x - 220 = 23
\]

Now, solve for \( x \):

1. Combine like terms:
\[
80 + x - 220 = 23
\]
\[
x - 140 = 23
\]

2. Add 140 to both sides to isolate \( x \):
\[
x - 140 + 140 = 23 + 140
\]
\[
x = 163
\]

Thus, the number of Post-it notes in the package she purchased is \(\boxed{163}\).
