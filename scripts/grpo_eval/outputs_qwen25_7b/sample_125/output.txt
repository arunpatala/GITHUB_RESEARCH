Let's denote the number of spoons in the package Julia bought as \( x \).

Initially, Julia had \( x \) spoons from the package she bought.

Her husband then gave her an additional package containing 5 spoons, so now she has:
\[ x + 5 \]

Julia used 3 spoons to sample her stew, so the number of spoons left is:
\[ (x + 5) - 3 = x + 2 \]

According to the problem, after using 3 spoons, Julia had a total of 12 spoons. Therefore, we can set up the equation:
\[ x + 2 = 12 \]

To find \( x \), we solve the equation:
\[ x + 2 - 2 = 12 - 2 \]
\[ x = 10 \]

Thus, the number of spoons in the package that Julia bought is \(\boxed{10}\).
