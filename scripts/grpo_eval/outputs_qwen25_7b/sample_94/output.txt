To solve this problem, we need to follow these steps:

1. **Identify the given information:**
   - Number of dogs (\(D\)) = 60
   - Number of cats (\(C\)) = \(2 \times D\) (since there are two cats for every dog)
   - The number of rabbits (\(R\)) is twelve less than the combined number of pet dogs and cats.

2. **Calculate the number of cats:**
   \[
   C = 2 \times D = 2 \times 60 = 120
   \]

3. **Calculate the combined number of dogs and cats:**
   \[
   D + C = 60 + 120 = 180
   \]

4. **Determine the number of rabbits:**
   \[
   R = (D + C) - 12 = 180 - 12 = 168
   \]

5. **Calculate the total number of pets:**
   \[
   \text{Total pets} = D + C + R = 60 + 120 + 168 = 348
   \]

#### 348
