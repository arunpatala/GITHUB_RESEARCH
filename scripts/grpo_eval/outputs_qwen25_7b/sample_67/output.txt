To find the total number of gems in the chest, we need to determine the number of each type of gem and then sum them up.

First, let's identify the number of rubies:
- The problem states that there are 35 fewer rubies than diamonds.
- There are 175 diamonds.
- Therefore, the number of rubies is \( 175 - 35 = 140 \).

Next, let's determine the number of emeralds:
- The problem states that there are twice the number of emeralds as the rubies.
- There are 140 rubies.
- Therefore, the number of emeralds is \( 2 \times 140 = 280 \).

Now, we can calculate the total number of gems by adding the number of diamonds, rubies, and emeralds:
\[
175 \text{ (diamonds)} + 140 \text{ (rubies)} + 280 \text{ (emeralds)} = 595
\]

Thus, the total number of gems in the chest is \(\boxed{595}\).
