To find out how many votes the loser got, we first need to determine how many votes the winner received. Since the winner got \( \frac{3}{4} \) of the total votes, we can calculate this as follows:

\[
\text{Votes for the winner} = \frac{3}{4} \times 80
\]

Performing the multiplication:

\[
\frac{3}{4} \times 80 = 60
\]

So, the winner received 60 votes. The total number of votes cast is 80, so the number of votes the loser received is:

\[
\text{Votes for the loser} = 80 - 60 = 20
\]

Thus, the number of votes the loser got is:

#### 20
