To solve this problem, we need to determine the number of sheep each city has based on the given relationships and then sum them up.

1. **Determine the number of sheep in Seattle:**
   - Seattle has 20 sheep.
   \[
   S = 20
   \]

2. **Determine the number of sheep in Charleston:**
   - Charleston has 4 times as many sheep as Seattle.
   \[
   C = 4 \times S = 4 \times 20 = 80
   \]

3. **Determine the number of sheep in Toulouse:**
   - Toulouse has twice as many sheep as Charleston.
   \[
   T = 2 \times C = 2 \times 80 = 160
   \]

4. **Calculate the total number of sheep:**
   - Add the number of sheep in Toulouse, Charleston, and Seattle.
   \[
   T + C + S = 160 + 80 + 20 = 260
   \]

#### 260
