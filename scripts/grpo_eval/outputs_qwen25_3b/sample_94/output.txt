To solve this problem, we need to determine the total number of pets in the neighborhood, which includes both dogs and rabbits.

1. **Determine the number of cats:**
   - We know that there are two cats for every dog.
   - Given that there are 60 dogs:
     \[
     \text{Number of cats} = 2 \times 60 = 120
     \]

2. **Calculate the combined number of dogs and cats:**
   - Adding the number of dogs and cats:
     \[
     \text{Total number of dogs and cats} = 60 + 120 = 180
     \]

3. **Determine the number of rabbits:**
   - The number of rabbits is twelve less than the combined number of dogs and cats.
   - Therefore:
     \[
     \text{Number of rabbits} = 180 - 12 = 168
     \]

4. **Calculate the total number of pets:**
   - Summing up the number of dogs, cats, and rabbits:
     \[
     \text{Total number of pets} = 60 + 120 + 168 = 348
     \]

Thus, the total number of pets in the neighborhood is \(\boxed{348}\).
