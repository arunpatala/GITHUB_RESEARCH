To solve this problem, we need to determine the number of red roses that Sandra ordered based on the information given.

1. Let \( c \) represent the number of white carnations Sandra ordered.
2. According to the problem, Sandra ordered four times as many red roses as white carnations. Therefore, the number of red roses is \( 4c \).
3. Sandra also ordered 200 pink calla lilies, and these are five times the number of white carnations. Thus, we can write:
   \[
   200 = 5c
   \]
4. Solving for \( c \):
   \[
   c = \frac{200}{5} = 40
   \]
5. Now, substituting \( c = 40 \) into the expression for the number of red roses:
   \[
   \text{Number of red roses} = 4c = 4 \times 40 = 160
   \]

Therefore, Fred must deliver 160 red roses by 5 pm to satisfy Sandra’s requirements. The final answer is:
####160
