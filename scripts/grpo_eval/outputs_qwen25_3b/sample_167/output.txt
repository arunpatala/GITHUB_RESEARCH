To solve this problem, we need to set up equations based on the information given.

Let's denote:
- \( S \) as Seth's current age.
- \( B \) as Brooke's current age.

From the problem statement, we have two pieces of information:

1. Seth is twice as old as Brooke:
\[ S = 2B \]

2. In 2 years, the sum of their ages will be 28:
\[ (S + 2) + (B + 2) = 28 \]

We can simplify the second equation:
\[ S + 2 + B + 2 = 28 \]
\[ S + B + 4 = 28 \]
\[ S + B = 24 \]

Now we have a system of linear equations:
1. \( S = 2B \)
2. \( S + B = 24 \)

We can substitute the first equation into the second equation:
\[ 2B + B = 24 \]
\[ 3B = 24 \]
\[ B = 8 \]

Now that we know Brooke's current age (\( B = 8 \)), we can find Seth's current age using the first equation:
\[ S = 2B \]
\[ S = 2 \times 8 \]
\[ S = 16 \]
