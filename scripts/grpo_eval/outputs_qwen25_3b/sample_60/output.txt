To solve this problem, we need to determine the number of good oranges in the basket.

First, let's break down the given information:
- Total number of oranges: 25
- Number of bad oranges: 1
- Percentage of unripe oranges: 20%
- Number of sour oranges: 2

We can start by calculating the number of unripe oranges. Since 20% of the oranges are unripe:

\[ \text{Number of unripe oranges} = 20\% \times 25 = 0.20 \times 25 = 5 \]

Next, we know there are 2 sour oranges. 

Now, let's sum up all the known quantities:
- Bad oranges: 1
- Unripe oranges: 5
- Sour oranges: 2

Adding these together gives us the total number of oranges that are not good:

\[ 1 + 5 + 2 = 8 \]

Since the total number of oranges is 25, the number of good oranges is:

\[ 25 - 8 = 17 \]

Thus, the number of good oranges is:

####17
