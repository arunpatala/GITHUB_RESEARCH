To determine the total number of gems in the treasure chest, we need to calculate the number of each type of gem and then sum them up.

First, let's find the number of rubies:
- The number of diamonds is given as 175.
- There are 35 fewer rubies than diamonds.

\[
\text{Number of rubies} = \text{Number of diamonds} - 35 = 175 - 35 = 140
\]

Next, we calculate the number of emeralds:
- The number of emeralds is twice the number of rubies.

\[
\text{Number of emeralds} = 2 \times \text{Number of rubies} = 2 \times 140 = 280
\]

Now, we sum the number of diamonds, rubies, and emeralds to find the total number of gems:

\[
\text{Total number of gems} = \text{Number of diamonds} + \text{Number of rubies} + \text{Number of emeralds}
\]
\[
\text{Total number of gems} = 175 + 140 + 280 = 595
\]

Thus, the total number of gems in the treasure chest is:

\boxed{595}
