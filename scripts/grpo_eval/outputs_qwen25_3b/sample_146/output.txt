To determine the total number of Lego pieces Johnny picks up, we need to calculate the number of pieces from each box and then sum them up.

1. **First Lego Box:**
   The first box contains 500 pieces.
   \[
   \text{Pieces in the first box} = 500
   \]

2. **Second Lego Box:**
   The second box has 3 times the number of pieces as the first box.
   \[
   \text{Pieces in the second box} = 3 \times 500 = 1500
   \]

3. **Third Lego Box:**
   The third box has \(\frac{1}{4}\) the number of pieces as the first box.
   \[
   \text{Pieces in the third box} = \frac{1}{4} \times 500 = 125
   \]

Next, we sum the pieces from all three boxes:
\[
\text{Total pieces} = 500 + 1500 + 125
\]

Adding these together:
\[
500 + 1500 = 2000
\]
\[
2000 + 125 = 2125
\]

Thus, the total number of Lego pieces Johnny picks up is:
\[
\boxed{2125}
\]
