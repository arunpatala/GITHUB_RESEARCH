To determine the total number of downloads for the program over the three months, we need to calculate the number of downloads for each month and then sum them up.

1. **First Month:**
   The program had 60 downloads.
   \[
   D_1 = 60
   \]

2. **Second Month:**
   The number of downloads in the second month was three times the number of downloads in the first month.
   \[
   D_2 = 3 \times D_1 = 3 \times 60 = 180
   \]

3. **Third Month:**
   The number of downloads in the third month was reduced by 30% from the second month's downloads.
   \[
   \text{Reduction} = 0.30 \times D_2 = 0.30 \times 180 = 54
   \]
   Therefore, the number of downloads in the third month is:
   \[
   D_3 = D_2 - 54 = 180 - 54 = 126
   \]

4. **Total Downloads Over Three Months:**
   Sum the downloads from all three months.
   \[
   \text{Total Downloads} = D_1 + D_2 + D_3 = 60 + 180 + 126 = 366
   \]

Thus, the total number of downloads over the three months is:
\[
\boxed{366}
\]
