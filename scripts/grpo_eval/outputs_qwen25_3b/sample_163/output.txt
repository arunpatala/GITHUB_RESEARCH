To solve this problem, we need to determine the total value of all the toys in the room.

1. **Determine the cost of one red car:**
   - We know that one red car costs $4.
   
2. **Determine the cost of one action figure:**
   - According to the problem, an action figure costs $5.

3. **Determine the cost of the doll:**
   - The doll costs as much as 3 action figures.
   - Since each action figure costs $5, the cost of 3 action figures is:
     \[
     3 \times 5 = 15 \text{ dollars}
     \]
   - Therefore, the doll costs $15.

4. **Calculate the total value of the red cars:**
   - There are 5 red cars, and each costs $4.
   - The total value of the red cars is:
     \[
     5 \times 4 = 20 \text{ dollars}
     \]

5. **Calculate the total value of the action figures:**
   - There are 3 action figures, and each costs $5.
   - The total value of the action figures is:
     \[
     3 \times 5 = 15 \text{ dollars}
     \]

6. **Calculate the total value of the doll:**
   - The doll costs $15.

7. **Sum up the values of all the toys:**
   - Total value of red cars: $20
   - Total value of action figures: $15
   - Total value of the doll: $15
   - Adding these together gives:
     \[
     20 + 15 + 15 = 50 \text{ dollars}
     \]

Thus, the total value of all the toys in the room is \(\boxed{50}\).
