To determine the total number of meters James runs in a week, we need to break down the problem step by step.

1. **Calculate the distance James runs per sprint:**
   James runs 60 meters per sprint.

2. **Determine the number of sprints James runs per day:**
   James runs 3 sprints each day.

3. **Calculate the total distance James runs per day:**
   \[
   \text{Distance per day} = \text{Number of sprints per day} \times \text{Distance per sprint}
   \]
   Substituting the given values:
   \[
   \text{Distance per day} = 3 \times 60 = 180 \text{ meters}
   \]

4. **Determine the number of days James runs per week:**
   James runs 3 times a week.

5. **Calculate the total distance James runs per week:**
   \[
   \text{Total distance per week} = \text{Distance per day} \times \text{Number of days per week}
   \]
   Substituting the given values:
   \[
   \text{Total distance per week} = 180 \times 3 = 540 \text{ meters}
   \]

Thus, the total number of meters James runs in a week is \(\boxed{540}\).
