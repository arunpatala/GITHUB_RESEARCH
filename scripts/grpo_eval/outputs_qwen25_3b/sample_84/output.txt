To solve this problem, we can set up an equation based on the information given.

Let's denote:
- \( W \) as the number of games they won.
- \( L \) as the number of games they lost.

From the problem statement, we know two things:
1. The total number of games played is 22.
2. They won 8 more games than they lost.

We can express these statements as equations:
\[ W + L = 22 \]
\[ W = L + 8 \]

Now, substitute the second equation into the first equation to solve for \( L \):
\[ (L + 8) + L = 22 \]
\[ 2L + 8 = 22 \]
\[ 2L = 14 \]
\[ L = 7 \]

Now that we have \( L \), we can find \( W \) using the second equation:
\[ W = L + 8 \]
\[ W = 7 + 8 \]
\[ W = 15 \]

So, the number of games they won is 15. Therefore, the answer is ####15.
