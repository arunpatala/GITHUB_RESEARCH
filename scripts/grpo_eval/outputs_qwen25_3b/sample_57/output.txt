To determine the maximum number of boxes that can be loaded onto the truck without exceeding the bridge's weight limit, we need to follow these steps:

1. **Identify the total weight capacity of the bridge:**
   \[
   \text{Bridge's weight limit} = 5000 \text{ pounds}
   \]

2. **Determine the weight of the driver and the empty truck:**
   \[
   \text{Weight of the driver and empty truck} = 3755 \text{ pounds}
   \]

3. **Calculate the remaining weight capacity for the boxes:**
   \[
   \text{Remaining weight capacity} = \text{Bridge's weight limit} - \text{Weight of the driver and empty truck}
   \]
   \[
   \text{Remaining weight capacity} = 5000 - 3755 = 1245 \text{ pounds}
   \]

4. **Determine the weight of each box:**
   \[
   \text{Weight of each box} = 15 \text{ pounds}
   \]

5. **Calculate the maximum number of boxes that can be loaded:**
   \[
   \text{Maximum number of boxes} = \left\lfloor \frac{\text{Remaining weight capacity}}{\text{Weight of each box}} \right\rfloor
   \]
   \[
   \text{Maximum number of boxes} = \left\lfloor \frac{1245}{15} \right\rfloor
   \]

6. **Perform the division:**
   \[
   \frac{1245}{15} = 83
   \]

Since 83 is an integer, there are no fractional boxes, so the maximum number of boxes that can be loaded is:
\[
\boxed{83}
\]
