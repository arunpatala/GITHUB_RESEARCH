To solve the problem, we need to determine the total number of friends that Amy and Lily have together.

First, we know from the problem statement that Lily made 50 friends. Let's denote the number of friends Lily has as \( L \). Therefore:
\[ L = 50 \]

Next, we are told that Amy made 20 more friends than Lily. Let's denote the number of friends Amy has as \( A \). Therefore:
\[ A = L + 20 \]

Substituting the value of \( L \) into the equation for \( A \):
\[ A = 50 + 20 \]
\[ A = 70 \]

Now, we need to find the total number of friends that both Amy and Lily have together. We add the number of friends each has:
\[ \text{Total friends} = A + L \]
\[ \text{Total friends} = 70 + 50 \]
\[ \text{Total friends} = 120 \]

Thus, the total number of friends that Amy and Lily have together is:
####120
