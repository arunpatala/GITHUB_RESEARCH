To solve this problem, we need to determine the number of worker bees given the relationships between the different types of bees.

Let's define:
- \( Q \) as the number of queens.
- \( B \) as the number of baby bees.
- \( W \) as the number of worker bees.

From the problem statement, we have the following relationships:
1. The total number of bees is 700.
2. There are twice as many worker bees as baby bees: \( W = 2B \).
3. There are twice as many baby bees as queens: \( B = 2Q \).

We can use these relationships to express everything in terms of \( Q \):

First, substitute \( B \) with \( 2Q \):
\[ W = 2B = 2(2Q) = 4Q \]

Now, sum up all the bees:
\[ W + B + Q = 700 \]
Substitute \( W \) and \( B \) with their expressions in terms of \( Q \):
\[ 4Q + 2Q + Q = 700 \]

Combine like terms:
\[ 7Q = 700 \]

Solve for \( Q \):
\[ Q = \frac{700}{7} = 100 \]

Now that we know \( Q = 100 \), we can find \( B \) and \( W \):
\[ B = 2Q = 2 \times 100 = 200 \]
\[ W = 4Q = 4 \times 100 = 400 \]

Thus, the number of worker bees is:
\boxed{400}
