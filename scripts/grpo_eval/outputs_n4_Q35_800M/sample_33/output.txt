Let $g$ be the number of gold coins and $s$ be the number of silver coins.

We are given two conditions:
1. The total number of coins is 110.
2. There are 30 more gold coins than silver coins.

We can formulate a system of equations:
1. $s + g = 110$
2. $g = s + 30$

First, substitute the second equation into the first equation:
$s + (s + 30) = 110$

Combine like terms:
$2s + 30 = 110$

Subtract 30 from both sides:
$2s = 80$

Divide by 2:
$s = 40$

Now that we know the number of silver coins is 40, we can find the number of gold coins using equation (2):
$g = 40 + 30$
$g = 70$

Alternatively, using equation (1) directly: $70 + 40 = 110$.

Numbers of gold coins: 70.
